# Project Work L-31 — Apofruit Sostenibilità

Artefatto web realizzato da **Giorgio Giardina** per il corso di laurea
**Informatica per le Aziende Digitali (L-31)**.

## Traccia

Tema 3 — *Tecnologia web per la sostenibilità d’impresa*  
PW 17 — *Sviluppo di una pagina web per il download dei report di
sostenibilità di un’impresa del settore primario*.

## Obiettivo

Il progetto presenta il caso di **Apofruit Italia Società Cooperativa
Agricola** e rende facilmente consultabile il suo primo Report di
sostenibilità, relativo all’esercizio 2024.

La pagina:

- introduce l’impresa e il suo modello cooperativo;
- sintetizza le principali aree ambientali, sociali e di governance;
- propone una lettura critica del documento;
- collega il PDF pubblicato sul sito istituzionale di Apofruit;
- documenta le principali scelte di usabilità e accessibilità.

## Come verificare il sito

Il progetto è statico e non richiede installazione.

1. Scaricare o clonare il repository.
2. Mantenere `index.html` e `style.css` nella stessa cartella.
3. Aprire `index.html` con un browser moderno.

Il repository pubblico consente inoltre di consultare direttamente tutti i
file sorgenti e la relativa cronologia.

## Scelte tecniche

- HTML5 semantico.
- CSS responsive senza framework.
- Nessun JavaScript, database o dipendenza esterna.
- Navigazione interna, skip link e focus da tastiera visibile.
- Contrasto elevato e supporto a `prefers-reduced-motion`.
- Nessun cookie e nessuna raccolta di dati personali.

La soluzione statica è intenzionale: soddisfa il requisito di divulgazione e
download mantenendo il codice leggero, trasparente e facilmente valutabile.
